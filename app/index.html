SourceMedian — the station pages

Five public pages, read by a live contract on GenLayer Studio Network.

Each page is one independent source. The contract fetches the pages, asks one consensus round for the number each source reports, drops the sources that say nothing, and takes the median of the rest.

The sources

  • station-a.html — Station A, reports 42 credits
  • station-b.html — Station B, reports 42 credits
  • station-c.html — Station C, reports 42 credits
  • station-outlier.html — Station D, reports 97 credits, far from the others
  • station-broken.html — Station E, offline, publishes no number

What the live run does with them

  • credits-1 — A, B and C. All three say 42, so the median is 42, the spread is 0 and the reading is reliable.
  • credits-2 — A, B and the outlier. The median stays 42, the spread is 55, and the reading is marked unreliable.
  • credits-3 — A, B and the offline station, with min_sources 3. Only two sources say anything, so the read is refused and nothing is stored.
